# v0.4.0: real screenshots for agents

Agents can now **see** their games, not just simulate them.

```bash
npx @ludra/cli play --inputs "right:1s, right+jump:0.45s" --screenshot 0.5s,2s,end
```

## Highlights

- **`ludra play --screenshot`** renders exact moments of a deterministic run with the same renderer players use (sprites, animation, particles) and saves them as PNGs. Multimodal agents like Claude open the images and judge the visuals: a sprite floating or sinking, facing the wrong way, or lost against the background.
- **No new dependencies.**
  - Ludra drives the Chrome, Edge or Chromium already on the machine, headless over the DevTools protocol, using Node's built-in WebSocket. `LUDRA_BROWSER` overrides the browser.
  - The browser and its temporary profile are cleaned up afterwards.
- **`--out`** picks the folder (default `screenshots/`), and `--json` includes the file paths.
- **New projects** get a `.gitignore` that ignores `screenshots/`.
- **The skill** gains a **Look** step: after every visual change, take screenshots and look at them.
- **The README** opens with a GIF of the platformer template, replayed from its own winning test.
