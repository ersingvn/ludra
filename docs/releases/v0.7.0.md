# v0.7.0: blocks, genres and art without limits

Two versions in one release: **v0.6** (a block library and a design guide) and **v0.7** (new genres, bounce physics, and art without limits). v0.6 was never published on its own.

## Art without limits (v0.7)

No preset menu: the agent gets the whole canvas.

- **`draw` / `drawUI` script hooks** receive the real Canvas 2D context: gradients, glow, additive light, text, filters.
  - `drawUI` replaces the default HUD and win screen.
  - Helpers on `ctx`: `time`, `local`, `view`, `recent(event)`, `image`, `burst`, `shake`, `random`.
- **Scene `fonts`**: Google Fonts or font files.
- **Scene `postfx`**: a GLSL fragment shader over every frame, with custom uniforms. Headless screenshots render it too.
- **Draw hooks are read-only**: changing the game from one throws, so the browser can never drift from what tests verified.
- **`ludra check`** runs draw hooks against a mock canvas (`E_DRAW_HOOK`).

## Genres (v0.7)

- **`topdown` component**: movement seen from above in 8 directions, 4 directions, or a single axis (paddles).
- **`body.bounce`**: balls that rebound, with a `bounce` event.
- **Paddles**: player-steered kinematic bodies stop at walls.
- **Two new templates**, each with tests proving it can be won without dying:
  - **Neon Breakout**: synthwave, drawn entirely in code. Its winning route came from an autopilot, a technique the skill now teaches.
  - **Crystal Grove**: a moonlit top-down grove lit by code over SVG sprites.
- **The skill** now covers every genre.

## Blocks and taste (v0.6)

- **`ludra blocks` / `ludra add <block> --at x,y`**: 11 tested gameplay blocks with scripts, art and effects:
  - `jump-pad`, `key-and-door`, `chasing-enemy`, `patrol-enemy`, `moving-platform`, `spikes`
  - `coin-row`, `turret`, `falling-platform`, `teleporter`, `time-limit`
- **Several copies get unique, linked ids**, and files you changed are never overwritten.
- **Each block ships a demo level whose tests run in CI.**
- **`DESIGN.md` in the skill**, a design guide covering:
  - level design: teach, test, twist
  - fairness you can prove: timing windows of at least 0.2 s
  - game feel, palettes and SVG art direction
  - a "Paint with code" guide and a finishing checklist

## Tooling

- **Scripts can read `world.won` and `world.deaths`.**
- **`npm run check:scripts`** type-checks every shipped game script.
- **CI** tests every template and installs each one from the packed packages.
