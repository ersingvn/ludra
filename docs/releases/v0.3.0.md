# v0.3.0: the first tagged release (sprites, particles, sound)

The first tagged release of **Ludra**, the game engine built for AI agents. It covers everything from the initial v0.1 through v0.3.

> **Note:** only `@ludra/core@0.3.0` reached npm. npm rejected the CLI's unscoped name `ludra` as too similar to `lunr`. **Use [v0.3.1](https://github.com/ersingvn/ludra/releases/tag/v0.3.1) or later**, where the CLI is published as `@ludra/cli`.

## Highlights

- **Games as text**: scenes are JSON, with entities made of components (`transform`, `body`, `sprite`, `platformer`, `collectible`, `camera`).
- **The agent loop**: everything an agent needs to work without a human, all deterministic at a fixed 60 Hz:
  - `ludra check` gives diagnostics with a JSON path and a `fix:`.
  - `ludra play` runs a headless simulation with a timeline, events and an ASCII map.
  - `ludra test` runs scripted inputs against assertions.
  - `ludra components` prints a reference generated from the engine.
  - `ludra dev` plays the game in the browser.
- **v0.2, gameplay**: `patrol` (moving platforms that carry the player, walking enemies), `hazard` (with `stompable` enemies), `goal` (with `requireScore`), and falling out of the world counts as a death.
- **v0.3, looks and sound**:
  - SVG/PNG sprites, animated spritesheets (idle/run/jump/fall), tiles and mirroring.
  - Scene `effects` add particles, screen shake and sound to game events, and an `emitter` streams particles.
  - Seven synthesized sound presets, so no audio files are needed.
- **Claude Code plugin**:

  ```
  /plugin marketplace add ersingvn/ludra
  /plugin install ludra@ludra
  ```

  The `make-2d-platformer-games` skill teaches Claude the whole loop.
- **Platformer template** with hand-written SVG art and a test that proves the level can be won without dying.
