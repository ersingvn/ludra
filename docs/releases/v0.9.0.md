# v0.9.0: real physics, a game's own sound, and bigger worlds

The AI is the artist, and Ludra keeps taking ceilings away. This release adds a real physics engine, sound and music with no limits, and the tools for bigger worlds. Quality still comes from guidance and verification: everything new is deterministic, testable, and checked by `ludra review`.

```bash
npx @ludra/cli new my-game --template physics
npx @ludra/cli components sounds
```

## Real physics: `@ludra/physics`

Set `"world": { "physics": "rapier" }` and a scene runs on [Rapier](https://rapier.rs). Arcade physics stays the default and is unchanged, frame for frame.

- **Bodies rotate, roll and tip over.**
  - Shapes: `circle`, `capsule`, `polygon` and `polyline`.
  - `friction`, `density`, `fixedRotation` and `bullet` (continuous collision).
- **Joints**: `revolute` (hinges), `prismatic` (sliders), `fixed`, `rope` and `spring`, with limits and motors. A body can have a list of joints, which bridges, ragdolls and vehicles need.
- **Players use Rapier's character controller**:
  - slope limits (`maxSlope`) and stairs (`stepHeight`);
  - pushing crates (`push`), riding moving platforms, and coyote time.
- **Scripts get forces and rays**:
  - `self.applyImpulse`, `self.applyForce`, `self.mass`, `self.rotation`, `self.angularVelocity`;
  - `world.raycast(from, to)`;
  - `world.physics.raw`, the whole Rapier API, for anything the components don't cover.
- **Deterministic everywhere.** A golden hash test proves that 6 CI machines (Linux, Windows, macOS × Node 22 and 24) simulate exactly the same frames. The browser runs the same WebAssembly, so tests stay valid.
- **See it**: rotated sprites and round shapes are drawn as they are. `play --screenshot --debug`, or the backquote key in the browser, shows colliders, joints, velocities and ids.

### New template: Crate & Chasm

`npx @ludra/cli new my-game --template physics`:
- Push a crate to the foot of a cliff and climb it.
- Cross a rope bridge of jointed planks.
- Time your run under a swinging spiked pendulum.

Its tests cover each piece and a full route without dying.

## Sound and music, without limits

Seven stock beeps are no longer the palette.

- **`"sounds"`**: a scene designs its own sounds from tone and noise layers. `vary` changes the pitch on every play, so repeats never sound copied. Effects and scripts use them by name.
- **`"music"`**: tracks of notes that loop. Chords, rests, holds, and noise drums (kicks, hats), or an audio file. The same music carries on across scenes; different music crossfades.
- **The `sound` hook** gives scripts the real Web Audio API, the way draw hooks get the real canvas. Crate & Chasm's wind grows as you climb, the pendulum hisses as fast as it swings, the crate scrapes and the bridge creaks.
- **Mixing**: a master compressor; mute and restart are handled.
- **Checks**: `ludra review` flags games that only use presets (`R_STOCK_SOUNDS`) or have no music (`R_NO_MUSIC`).
- **Templates**: every template now has its own sounds and music.

Run `ludra components sounds` for every field and an example of each.

## Bigger worlds

- **`tilemap`**: draw a level as rows of characters.
  - Tiles merge into big colliders, and letters place prefabs.
  - Each cell becomes an ordinary entity (`map-3-7`), so tests and scripts can use it.
  - `check` names a character missing from the legend by row and column.
- **`cameraZone`**: rooms the view stays inside, fixed shots and zooms, eased over `blend` seconds. Zones show as violet frames in `--debug`.
- **`tween`**: ease `x`, `y`, `rotation`, `scale` or `opacity`.
  - 9 curves, and `once`, `loop` or `pingpong` with a delay before every pass.
  - `"on": "<event>"` starts a tween when that event fires; scripts call `self.tween()`.
  - Tweens run in the simulation, so tests see them, and tweened platforms carry the player.
- **Sprites** gain `scale` and `opacity`.

### New example: Clockwork Keep

[`examples/clockwork-keep`](../../examples/clockwork-keep) is a two-floor castle that uses all three:
- The whole level is a tilemap.
- Each floor is a camera room, and the finish eases out to show the whole keep.
- A lift rests at each floor, a gate rises when you light the lantern, a platform glides over spikes, and coins bob.

## Upgrading

- Projects: `npm install @ludra/cli@^0.9.0`. Nothing breaks. Arcade games simulate exactly as before; `ludra review` now also asks for the game's own sounds and music.
- `@ludra/physics` is a new package that `@ludra/cli` depends on. The CLI loads it on its own when a scene says `"physics": "rapier"`.
