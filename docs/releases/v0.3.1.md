# v0.3.1: the CLI is now @ludra/cli

The first complete npm release: the CLI is now **`@ludra/cli`**.

```bash
npx @ludra/cli new my-game
```

## Changes

- **The CLI is published as [`@ludra/cli`](https://www.npmjs.com/package/@ludra/cli).**
  - npm blocked the unscoped name `ludra` as too similar to `lunr`. The scoped name avoids that check, and the command is still `ludra`.
  - Always write the full `@ludra/cli`; a bare `npx ludra` fetches an unrelated package.
- **Docs and templates** (skill, READMEs, template and example `CLAUDE.md` files, and the hints `ludra new` prints) all use `npx @ludra/cli`. New projects depend on `@ludra/cli`.
- **Resumable releases**: the release workflow skips versions already on npm, so a release that fails halfway can be finished by re-running it.
- **`bin`** is written the way npm expects, so publishing no longer prints a misleading "bin was removed" warning.

Published: [`@ludra/core@0.3.1`](https://www.npmjs.com/package/@ludra/core/v/0.3.1) and [`@ludra/cli@0.3.1`](https://www.npmjs.com/package/@ludra/cli/v/0.3.1), with provenance.
