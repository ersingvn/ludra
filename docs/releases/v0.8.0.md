# v0.8.0: ludra review, lives, checkpoints, prefabs and levels

Ludra's promise, made explicit: **no ceiling on creativity, no slop.** This release adds the tool that tells an agent when a game is finished rather than just working, and the structure real games need: lives, checkpoints, reusable prefabs and several levels.

```bash
npx @ludra/cli new my-game        # now two levels
npx @ludra/cli review my-game
```

## `ludra review`

`check` asks whether a game is valid and `test` asks whether it works. `review` asks whether it would pass as finished. It runs every test, reads the scenes and scripts, and flags the signs of slop:

```
Proof: is it shown to work?
  ✗ scripts/chase.ts (on chaser) has no test that checks what it does.
Feel: does every moment answer the player?
  ✗ These events happen in play but nothing answers them: collect, die.
Looks: does it have a style of its own?
  ✗ It uses the engine's default HUD and end screens.
  ✗ Behind the game there is only a flat background color.
  ○ No post-processing.
```

- **Areas**: proof (a win without deaths, every mechanic tested), feel (no silent events), looks (no default HUD, flat backdrop or plain shapes) and identity (a real name).
- **Every finding comes with a fix.** Issues (✗) mean the game isn't done; ideas (○) are worth considering.
- **`--strict`** exits 1 on issues. CI runs it on every template, and the skill treats issues like failing tests.

## Game structure

- **Lives**: `"world": { "lives": 3 }`. The last death ends the game (`lost`, a `gameover` event). Scripts can read and write `world.lives` and call `world.lose()`.
- **Checkpoints**: the `checkpoint` component moves the player's respawn point to it.
- **Prefabs**: `prefabs/slime.prefab.json`, shared by every scene. Entities use `"prefab": "slime"` and list only what differs; `world.spawn({ prefab })` works too.
- **Multiple scenes**: a goal's `next` or `world.goto()` from a script (title screens, doors) moves on to another scene, carrying score, deaths and lives.
  - `check` validates every scene.
  - Tests can pick a scene with `"scene"`.
  - `play` takes `--scene`.

## Templates

- **The platformer is now two levels**, *Night Meadow* and *Moonlit Cliffs*, built from coin and slime prefabs:
  - 3 lives and a lantern checkpoint that lights up.
  - Its own HUD with hearts, points, a title card and end screens.
  - A parallax night sky and a glow shader.
  - Fairness checked: every timing window was swept.
- **Neon Breakout** gets 3 balls and a game-over screen.
- **All three templates review clean.**
